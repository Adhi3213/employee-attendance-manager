# Employee Attendance Manager

A beginner-friendly frontend portfolio project built with HTML, CSS and vanilla JavaScript.

## Features
- Add and delete employees
- Mark daily attendance as Present or Absent
- Record check-in and check-out times
- Search employees by name, department or ID
- View attendance totals for the selected date
- Save data in the browser with `localStorage`
- Export the selected date's records as CSV
- Responsive layout for smaller screens

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a current web browser.
3. Click **Load sample employees** or add your own sample employee records.
4. Try marking attendance, changing the date, searching and exporting CSV.

No build tools or dependencies are required.

## Important limitations
This is a frontend learning/demo project. It does not have a backend server, shared database, authentication, access controls or production-grade employee data security. Data stays in the current browser profile. Use sample data only.
